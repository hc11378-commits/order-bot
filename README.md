# 機場接送與桃小巴 LINE Bot

目前版本：`2.3.0-fused`

本 Bot 用於 LINE 司機群組，可辨識機場接送訂單與桃小巴班次、產生每日簡表、處理拉回與改派、統計月結並匯出 Excel。所有資料均依 LINE 群組隔離，不會混入其他司機群組。

## 快速開始

在 LINE 群組輸入：

```text
測試
```

正常回覆：

```text
BOT 測試成功 ✅
版本：2.3.0-fused
```

輸入以下任一指令可查看 Bot 內建說明：

```text
指令
說明
help
```

| `指令` | 顯示內建指令 | 否 |
| `說明` | 顯示內建指令 | 否 |

## 每日簡表

查詢目前群組最近服務日：

```text
簡表
```

查詢指定日期：

```text
簡表 11/6
```

查詢指定年度日期：

```text
簡表 2026/11/6
簡表 2026-11-6
```

簡表顯示時間、接送方向、縣市行政區、人數、結算價、客收、業績及必要備註。若目前群組、目前服務日收到桃小巴班次，會依開始時間併入簡表，並另外顯示桃小巴時數與業績。顧客姓名、電話、LINE ID、禁煙文字及無關自由備註不會出現在簡表。

## 群組診斷

群組診斷為只讀功能，不會新增、取消或修改訂單。

```text
群組診斷
群組診斷 11/6
群組診斷 2026/11/6
```

診斷內容包含 Bot 版本、執行時間、檢查服務日、匿名群組代碼、有效訂單數、結算價、客收、業績及服務日訂單。

訂單數量或金額有疑問時，請先執行群組診斷。

## 月結與 Excel

### 文字月結

```text
月結
月結 11
月結11
月結 11月
月結 2026/11
月結 2026年11月
月結 2026-11
```

月結內容包含資料涵蓋日期、機場接送總趟數、結算價、客收、業績、平均每趟業績、待確認筆數、每日明細及必要備註統計。有桃小巴班次時，另列班次、時數及桃小巴業績。

計算方式：

```text
業績＝結算價＋客收－舉牌服務扣款
```

只有客收、沒有結算價的自客單，客收會直接列入業績。

一般舉牌訂單每筆扣除 100 元；舉牌訂單文字只要同時出現「自接」，或司機回覆原始舉牌訂單時輸入含「自接」的文字，該筆不扣 100 元。

### 月結 Excel

```text
月結 Excel
月結 xlsx
月結 11月 Excel
月結 11 xlsx
月結 2026/11 Excel
月結 2026年11月 Excel
```

Bot 會回覆 24 小時有效的下載連結。Excel 包含月結總表、每日統計與訂單明細；桃小巴時數與業績會分欄顯示，且只會匯出目前 LINE 群組的資料。

## 新增訂單

完整訂單直接貼入 LINE 群組，不需要先輸入指令。

```text
休旅送機
ABC12345
出發日期：11/7 04:20
乘車人數：2
行李數量：2
航班編號：BR123
上車地點：新北市中和區連城路1號
中間點：新北市新莊區福美街1號
下車地點：桃園機場第二航廈
其他備註：安全座椅1張
聯絡人：王小姐
電話：0900000000
結算價：900
```

自客單只有客收也可以：

```text
出發日期：11/7 04:20
乘車人數：2
行李數量：2
航班編號：BR123
上車地點：新北市中和區連城路1號
下車地點：桃園機場第二航廈
其他備註：
聯絡人：王小姐
電話：0900000000
客收：900
```

這筆自客單的結算價為 0、客收為 900、業績為 900。

若日期、時間或上下車地點無法辨識，Bot 不會儲存訂單。

## 批次異動

逐行輸入多筆訂單編號，最後輸入共同動作：

```text
XJQ798147
ZUF777274
SCC907815

以上取消
```

最後一行支援：

```text
以上取消
以上收回
以上拉回
以上改派
以上拉回改派
```

也可使用單行格式：

```text
取消：XJQ798147、ZUF777274、SCC907815
拉回：XJQ798147、ZUF777274、SCC907815
改派：XJQ798147、ZUF777274、SCC907815
拉回改派：XJQ798147、ZUF777274、SCC907815
```

系統會回覆完成筆數、失敗筆數、失敗編號及受影響日期的最新簡表。自動化測試已涵蓋一次處理 100 筆。

若批次中某一筆要保留：

```text
XJQ798147
ZUF777274
SCC907815
XJQ798147 不要取消

以上取消
```

此時只會取消另外兩筆。

下列文字不會被誤判成取消指令：

```text
ABC12345 不要取消
ABC12345 尚未取消
ABC12345 是否取消？
航班取消 ABC12345
其他備註：ABC12345 取消費200
```

單純寫「航班取消」不會取消訂單。要取消訂單，必須輸入 `訂單編號 取消`。

## 舉牌服務與自接

訂單備註包含 `舉牌` 時，系統預設每筆扣除 100 元舉牌服務費。原始結算價不會被修改，扣款會獨立顯示，業績依下列方式計算：

```text
業績＝結算價＋客收－舉牌服務扣款
```

### 一般由外部人員舉牌

不需要輸入額外指令。簡表會保留：

```text
舉牌
```

並在總額區顯示：

```text
舉牌服務扣款：100（1筆）
```

### 客上自接或司機自接

有兩種辨識方式：

1. 原始舉牌訂單的文字中只要出現「自接」兩字，系統會直接判定為司機自接。
2. 訂單已貼出後，司機在 LINE 使用「回覆」功能回覆原始舉牌訂單，回覆文字只要包含「自接」兩字即可。

例如：

```text
客上自接
```

```text
司機自接
```

```text
這筆我來自接，謝謝
```

訂單已貼出後，請勿只在群組輸入「自接」而沒有回覆原始訂單，否則 Bot 無法知道要修改哪一筆訂單。

標記成功後，該筆簡表仍保留舉牌字樣，但會顯示星號：

```text
舉牌*
```

星號代表：

```text
*：客上自接／司機自接，本筆不扣舉牌服務費
```

自接標記只會作用於：

- 目前 LINE 群組。
- 被回覆的原始 LINE 訊息。
- 尚未取消的有效舉牌訂單。

不會影響其他司機群組，也不會用日期、時間或金額猜測訂單。

月結、群組診斷與 Excel 會使用相同扣款口徑。Excel 會另外顯示「舉牌扣款」欄位，必要備註仍保留 `舉牌` 或 `舉牌*`。

## 補單

補單是簡表上的佔位提示，不列入趟數、結算價、客收或月結業績。

### 補送

```text
22補
補00送
補04送
補22送
補22送機
補0430送
補04:30送
補0430的送
```

沒有寫接或送時，預設為送機。

### 補接

```text
0430補接
補04接
補04:30接
```

整點補單一律使用兩位數小時顯示，範圍為 `00`～`23`。例如輸入 `補04接`，簡表顯示 `補04接`，不會縮成 `補4接`。

### 指定日期

```text
11/7 22補
11/7 補0430送
```

未指定日期時，補單會放入目前群組最近的服務日；群組沒有任何訂單時才使用台灣時間當日。

### 取消補單

```text
取消補0430送
取消補04:30接
取消 11/7 22補
```

同一日期、時間及方向的補單重貼不會重複。不同分鐘視為不同補單。補單會保存至 MongoDB，Render 重啟後仍然存在。

當正式訂單補入後，如果日期與接送方向相同，且時間符合補單，系統會以正式訂單取代補單，簡表不會同時顯示兩筆。整點補單（例如 `補04接`）會對應 04:00～04:59；有分鐘的補單（例如 `補04:30接`）則精準對應 04:30。若該時段已經有正式訂單，再輸入相同補單也不會新增。

## 桃小巴

支援以下格式：

```text
1320-1520桃小巴
```

```text
11/8 0610-1410 桃小巴桃園區 一車
```

規則：

- 可使用 `1320` 或 `13:20` 格式。
- 有日期時使用指定日期；未寫日期時歸入目前群組最近的服務日，沒有既有資料時才使用台灣當日。
- 依開始時間與機場接送訂單一起排序。
- 桃小巴每 3 小時業績為 2,000 元，系統依實際分鐘比例換算。
- 例如 13:20～15:20 為 2 小時，桃小巴業績顯示 1,333.3 元。
- 例如 06:10～14:10 為 8 小時，桃小巴業績顯示 5,333.3 元。
- 桃小巴不列入機場接送趟數、結算價或客收；桃小巴時數與業績另外列出，最後再加入業績合計。
- 只有實際收到桃小巴班次的 LINE 群組與服務日才會顯示桃小巴欄位，不會讓其他司機的簡表出現桃小巴業績。
- 桃小巴班次會保存至 MongoDB，Render 重啟後仍可出現在簡表、月結與 Excel。

## 交通車提示

```text
0740 蘆竹交通車

```

## LINE 收回訊息

客服對原始訂單長按並選擇 LINE 的「收回」後，Bot 會：

1. 依原始 LINE 訊息 ID 找到訂單。
2. 只取消同一群組、同一則訊息產生的訂單。
3. 不影響其他司機群組。
4. 立即推送更新後的簡表。
5. 最後一筆被收回時，仍顯示零筆及零元總額。

建議 Render 設定：

```text
UNSEND_AUTO_PUSH=true
```

未設定時預設開啟，只有設定為 `false` 才會關閉。

必須使用 LINE 的「收回」，只在自己的手機刪除訊息不會通知 Bot。部署本版前沒有保存 LINE 訊息 ID 的舊訂單，仍需使用訂單編號取消。

## 停用指令

以下歷史修復指令已退役，輸入後不會修改資料：

```text
修復 已確認舊資料
修復 9/11 自客單
修正 9/7
```

資料有問題時，請改用：

```text
群組診斷 日期
```

## Render 設定

| 環境變數 | 內容 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Messaging API 長效 Token |
| `LINE_CHANNEL_SECRET` | LINE Channel secret |
| `MONGO_URI` | MongoDB Atlas 連線字串 |
| `TEST_MODE` | 測試時 `true`；正式運行 `false` |
| `UNSEND_AUTO_PUSH` | 建議設定為 `true` |

Render 服務設定：

```text
Build Command：npm ci
Start Command：npm start
Node：20 或 22
Webhook：https://order-bot-45x0.onrender.com/webhook
```

`TEST_MODE=true` 時，新訂單與文字指令使用 Reply 即時回覆，並停用每日及月底排程 Push。LINE 收回通知仍由 `UNSEND_AUTO_PUSH` 獨立控制。

`TEST_MODE=false` 時，一般訂單異動五分鐘後彙整推送；每日及月底排程恢復。LINE 收回事件不等待五分鐘，會立即推送。

## 建議日常流程

1. 收到客服訂單後確認 Bot 有產生簡表。
2. 出車前輸入 `簡表 日期`。
3. 數量或金額有疑問時輸入 `群組診斷 日期`。
4. 客服取消訂單時輸入 `訂單編號 取消`。
5. 未確定內容的時段使用 `補0430送`；正式訂單補入後系統會自動取代補單。
6. 補單不需要時輸入 `取消補0430送`。
7. 當日結束後再次輸入 `簡表 日期`。
8. 桃小巴班次直接貼入群組，例如 `11/8 0610-1410 桃小巴桃園區 一車`。
9. 月底輸入 `月結`；需要會計檔案時輸入 `月結 Excel`。
